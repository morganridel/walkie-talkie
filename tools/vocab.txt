# Copy to ~/.walkie-talkie/speechmatics-vocab.txt and edit that local copy.
# The app rereads it for each dictation; an absent or empty file sends no dictionary.
#
# Format: one term per line, or term: pronunciation, alternative pronunciation.
# Pronunciations must use the script of the language configured for Speechmatics.
# Add your own names and project terms locally. This template contains no personal
# names, sites, voice-corpus statistics, or language-specific pronunciation preset.
# Comments and blank lines are ignored.
